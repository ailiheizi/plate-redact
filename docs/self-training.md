# 自训练与数据回流

## 四条回流通道

| 通道 | 来源 | 用法 |
| --- | --- | --- |
| **Gold** | 真人确认的精确框 + 难负例（车灯 / 反光 / 车身字 / 路牌） | 微调学生 |
| **Silver** | 多教师或跨帧一致，但未经人工确认 | 训练**降权**，**绝不当负样本** |
| **HardNeg** | 难例挖掘（多引擎全漏 + 引擎冲突） | 降低误报 |
| **Unknown** | 分歧 / 极小 / 遮挡 | **不当普通背景负样本**，留在待决队列 |

两条纪律：**先按父视频隔离划出隐藏集**，再谈训练；自动标注量增加**不构成换模型的理由**。

## 伪标签怎么筛

- 开放词表教师出框 + 跟踪器多帧聚合取中位数收紧——实测优于让 VLM 直接标；
- 人工精标 200–800 帧作为干净验证集；
- 合成渲染车牌补「人眼可读但检测难」的样本。

## 端侧接入

- 部署包只放轻量检测器 + 跟踪 / 时序模块，**教师全部留在离线**；
- 量化优先 **w8a32**：权重 int8 影响小、激活 int8 会明显掉召回；
- 端侧路径 CoreML / NCNN / RKNN / TFLite；
- 未来可加「风险头」，但它只决定是否升级 ROI / 回溯，**不能凭几何生框**。

## 完成度（如实写）

- 路线图：**只写了设计**；
- 难例挖掘脚本：已实现，**没有跑批结论**；
- 用教师标注数据做的微调：**跑过 4 轮，指标不足以支撑换模型，正式权重未替换**；
- 结论：这条路线目前停在「实验过、未采用」，不是「尚未开始」。
