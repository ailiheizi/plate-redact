> 本文是**规模与状态的只读快照**：目录有多少素材、一次全片 strict 跑出多少轨迹和多少队列项、
> 教师侧的运行规模有多大。所有数字都标了「测什么 / 样本 / 状态」，

> 也不记录任何源 / 输出哈希值。

再补四条最强的「1–2 hit、几何合理」单帧洞；风险排序依次考虑车牌形状、
独立检测家族数、轨迹命中数和 OCR 多样性。相同 / 重叠的时间窗口只扫一次，
但**同帧的不同空间位置不会被误合并**。

融合门槛（摘要）：低阈值候选与队列 bbox 在同一锚点 IoU ≥ 0.30 且语义教师确认存在牌区，
才可称「可信 teacher anchor」；时序教师的 mask bbox 超过锚框 12 倍、漂到车身或邻车都算分歧；
**三教师一致也只是 teacher evidence**。

## 7. 生命周期与恢复阻塞清单

| 阻塞 | 当前证据 | 恢复所需的最小改变 | 未完成前状态 |
| --- | --- | --- | --- |
| 分割教师权重 | 本地 checkpoint 不存在，preflight `blocked_missing_model` | 合规取得并用冻结输入校验哈希，新建 run | `BLOCKED` |
| 独立评测 GT | 无完整 `readability_gt` / `geometry_gt` / track manifest | 人工制作两套逐帧 GT，按 parent video 锁定 split | `INCOMPLETE` |
| YOLO12 / RT-DETR 正式 shadow | 仅短训练或 shape smoke | 足够算力 + 新哈希绑定 run + 无提示全帧候选和分层指标 | `NOT_ELIGIBLE` |
| 真人 attestation | 没有有效 `proposal digest` 绑定 | 对候选做真人两阶段确认并持久化 | **不得写 Gold / 放行** |
| 某 stem 的未释放 lease | lock 仍在，PID 已死，draft 写完但收尾证据缺失 | **人工隔离核查后显式归档**；不得删除、抢占、自动清理 | stem 级硬阻断 |
| 某队列目录的 `st_dev` 漂移 | inode / size / 内容 SHA 未漂移，但 device 变了 | 在新的随机私有 run 中重新提取 | fresh verifier `DENIED` |
| 后审计的 pre-fix 缺陷 | 计划覆盖率达到 98% 时可能**跳过** post-audit；覆盖不足但纹理低时也可能不生成 issue | 先修复覆盖合同 / 审计并升级绑定 fingerprint，再用**全新 stem** 重跑 | 该轮证据**绝不可交付** |

最后一条是这套流程里最重要的反面教材：**一个「覆盖率够高就跳过检查」的快捷路径，
本质上是给 fail-closed 开了一个洞**。修复后的要求不是「跳过得更聪明」，
而是**要么完整跑，要么阻断**。
