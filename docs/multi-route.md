# 多重路线

同一个环节都留了不止一条路。下面按环节列，并标出哪些实测过、结论是什么。

## 1. 候选生成（并行取并集）

| 路线 | 作用 | 代价 |
| --- | --- | --- |
| 全帧低阈值 | 兜底，宁可多检 | 误报上升 |
| 重叠切片（2×2 / 640） | 补远距小目标 | 时间与误遮 |
| 逐车辆 ROI 放大 | 补小牌、暗牌 | 依赖车辆枚举质量 |
| 两轮车窄条兜底 | 补摩托 / 电动车窄牌 | 只是缓解，不算已证实 |
| 多引擎并集 | 覆盖各引擎的系统性盲区 | 算力 |

取舍是明确的：**用算力换召回**。配套约束是「任一补充引擎不可被静默关闭」。

## 2. 复核（两条独立审计 + 三档队列）

- **车牌审计**：计划框在成品里是否真的成了纯色；
- **车辆覆盖审计**：每条车辆轨迹是否有可解释牌区；
- **队列优先级**：P0 计划外残留 / 疑可读 → P1 车辆无可解释牌区 → P2 普通分歧。

机器判不了的一律留 UNKNOWN 交真人，不靠「分数高就放行」。

## 3. 架构分叉（真跑过，结论相反）

| 版本 | 方案 | 实测结论 |
| --- | --- | --- |
| v9b / v12 | 单检测器 + OCR 只做确认层 | 曾是最优 |
| v10 | 车为中心、先建 tag 即打先验带 | **更差**：轨迹碎片化——贴边小牌覆盖 0%、打码面积 2.2%、整车误检 1（对照 82% / 0.5% / 0） |
| 现行 | 多引擎并集 + 时序冗余 | 回到并集路线，**与早期实验结论相反** |

这一层的价值不在「最后选了哪个」，而在**两条路都跑过，并且写下来为什么换**。

## 4. 模型替换

- YOLO12n / RT-DETR-L：只做到 shape 冒烟，**未达标**（数据不足）；
- YOLOX-Nano ONNX：**可做许可证审查的替换路线**，仍在实验，未换默认；
- SAM3 → SAM2.1：授权阻塞后的替代。

## 5. 明确不做

全帧切片提分辨率、为 RL 换检测器、把世界模型当检测器、像素级无证据外推。
