# 实测与负结果

> 全部是**自测口径**：单源、自标注、非独立盲测。没有独立盲测的召回率，也没有一次全片 `UNKNOWN = 0` 的通过记录。

## 1. 自标 GT 消融（同一段 1280×720 / 1800 帧基准片，90 帧 / 133 个可读牌框）

| 配置 | 结果 |
| --- | --- |
| 单帧基线 | 119/133 = **89.5%** |
| + conf 0.03 | 121/133 = **91.0%** |
| + 2×2 重叠切片 | 124/133 = **93.2%** |
| + 全片轨迹补洞与回溯 | 131/133 = **98.5%** |

时序冗余的收益主要来自最后一步。剩余盲区是两个 28×16 / 32×26 像素的极小框；
14 个历史漏检全部 ≤34 px，放大 4 倍后人工判为「模糊不可读」。

## 2. 打码面积与效率

- 平均打码面积 5.48% → 1.1% → **0.8%**；中位 1.0%；单帧最大 **53% → 4.5%**；
- 时间驱动补检：待补检 1300 → **284（-78%）**，新增框 2184 → **355（-84%）**，总打码 6031 → 1458。

## 3. 多视图增量（同一 90 帧 / 133 框开发集，几何匹配口径）

baseline 125/133 → 车辆 ROI 放大 126/133（+17.25 s）→ 640 切片 125/133（+51.49 s）。
代价：mask 面积 +26%，且抽查发现新增候选里有车身大块与路侧设施误遮 →
该增强**只作候选、默认不开启**。

## 4. 教师侧耗时

- 小 VLM：**25.92 s/帧**（12 次有效计时均值）→ 按全片 94,228 帧折算约 **28.3 天**
  （折算值，不是实测）；72 帧批次总墙钟 1370.54 秒，峰值 RSS 约 3.63 GiB；
- 分割 / 时序教师：23 run / 230 方向帧 **230/230 成功**，每 run 中位数 25.31 s，
  引擎 attempt 累计 633.11 秒；207 个 run-local 唯一源帧中 206 帧有 mask
  （唯一空 mask 属一条已人工判为误报的轨迹）；9 帧双向 smoke 墙钟约 45.48 秒、
  最大 RSS 约 2.18 GB、peak footprint 约 3.99 GB、未观察到 swap/OOM；
  prompt 收紧后锚点凸包外接范围从约 73×37 收到 **32×17 源像素**（同一段 31/31 帧仍有 mask）；
- 开放词表教师：209 帧扫描出 2366 个候选（11.32 / 帧），推理 449.07 秒、墙钟 461.53 秒、
  峰值 RSS 约 2.96 GiB；与 20 个非 Gold 锚点空间一致只有 **8/20**（IoU ≥ 0.1 / 0.3 / 0.5 都是 8 个）
  ——不一致里 9 个是店招 / 广告 / 反光误报，2 个是真实牌区但在正常观看下因运动模糊不可读，
  1 个 21×12 px 仍 `UNKNOWN`。

## 4.1 教师侧的 A/B 与对照（同样是自测口径）

**小 VLM（2B 量级）**——测什么：语义判断能否当几何 / 放行依据。

| 数字 | 测什么 | 样本 | 状态 |
| --- | --- | --- | --- |
| 72/72 `UNKNOWN`（9 条有截断 / 格式 / 坐标错误） | 合并结论 | 72 帧 | `INCOMPLETE` |
| 4/4 报 `READABLE`，最大 IoU = **0** | 已知难例 | 4 帧 | 只能作风险报警 |
| `UNKNOWN` / 假 `READABLE` / 解析失败降级 `UNKNOWN` / 解析失败降级 `UNKNOWN` | 空标签对照 | 4 帧 | 对照级证据 |
| 2/2 `UNKNOWN` | 对已按计划遮挡的帧复问 | 2 帧 | 拿不到可用的"遮挡安全"负证据 |
| 3/3 越界被降为 `UNKNOWN` | 外扩 ROI 后的坐标 | 3 帧 | 严格 parser 正确拒绝 |

**开放词表检测教师**——测什么：低阈值枚举的可用性。

- 70 帧 / 234 候选，独立 verifier `integrity_ok=true`，但 `comparison_pass=false`；
  报告里的 `recall=1.0`、`precision=0.8` 是 **3 个抽样帧 / 8 个几何框、IoU 0.30**
  条件下的 harness 数字，报告自标 `not_formal_recall=true`；
- 另一个 23 帧窗口 **23/23 帧都有候选**；三个风险锚点的最佳框 IoU 为
  0.5951 / 0.7395 / 0.6972，其中一个最佳候选分数**仅 0.1018**
  → **教师枚举必须保留低阈值**，误报交给语义 / 时序教师消解。

**分割 / 时序教师（公开权重替代方案）**——测什么：给定车牌框后的双向传播质量。

- 三个已知真阳性均 9/9 唯一帧有 mask，坐标连续落在牌区；
- 扩到锚点 ±15 帧后 3 个 run 共 93 个唯一源帧、**93/93 有 mask**，
  双向重复锚点的 mask **逐字节一致**；
- 输出精度高度依赖初始的车牌级 prompt：换用同帧更紧的非 Gold 框重跑，
  仍 31/31 帧有 mask，但外接范围收紧到 32×17。

## 4.2 整片 VLM 审计的误报率（方法论负结果）

对一段 **1800 帧**成品逐帧做 VLM 审计，报出 **140 帧「漏打」**。
裁剪放大 8× + 双模型复查后，除 **1 帧**真实漏打外**全部是误报**：
模糊不可读的车牌被整帧误报为「可读」、路沿 / 导流线 / 反光被当成车牌、
以及对模糊牌**读出号码的幻觉**。

教训：**「模型读出一串号码」不能作为可读性证明**；整片审计必须配
「裁剪放大 + 双模型交叉验证」，或者回到本文档的口径——**用 fail-closed 的成品审计说话**，
而不是用模型的自述说话。

## 5. 工程缺陷（四个最小复现，已回归）

1. 两个扩张 mask 在 IoU 0.4857 时，第二个候选只被覆盖 **70%**（修复后完整覆盖）；
2. ONNX 传 `imgsz=640` 与 `1920`，实际预处理都是 **640×640**（参数无效）；
3. 检测分数 0.95 + 3 字符 OCR → 返回 **0 个候选**（门槛吞掉有效检测）；
4. 车辆门控在拿不到车辆框时**静默删掉候选**。

新增 19 项测试，其中多视图相关 17/17 通过。另有 150 组随机矩形并集 / 差集对照独立像素栅格计算；
合成重叠案例中第二候选由修复前 70% 覆盖变为完整覆盖，框外像素保持不变。
一份历史修正计划的 1327 项删除 / 替换涉及 595 帧，均有恢复的源像素，
因此新渲染门禁会**阻断**直接使用它——
但这个统计包含移除错误大框时恢复的车身和背景，**不是 595 帧已确认漏牌，也不是 1327 个真实车牌**。

## 6. 判定「不可行」的方案

| 方案 | 数字 | 结论 |
| --- | --- | --- |
| 小 VLM 当框教师 | 72 帧全跑 **72/72 UNKNOWN**；已知难例 4/4 报可读但 IoU = 0；峰值 3.63 GiB、墙钟 1370 s | 不能当框教师、OCR 教师或放行依据 |
| 车为中心 v10（400 帧） | 贴边小牌 **0%** vs 82%；面积 2.2% vs 0.5%；整车误检 1 vs 0 | 已停用 |
| 国外车牌引擎用于中文 | OCR 命中 **0/459** | 只引入误检 |
| YOLO12n / RT-DETR-L | 5 epoch 冒烟中断，仅 shape 通过 | 数据不足，不构成结论 |
