# 自训练与数据回流

## 四条回流通道

| 通道 | 来源 | 用法 |
| --- | --- | --- |
| **Gold** | 真人确认的精确框 + 难负例（车灯 / 反光 / 车身字 / 路牌） | 微调学生 |
| **Silver** | 多教师或跨帧一致，但未经人工确认 | 训练**降权**，**绝不当负样本** |
| **HardNeg** | 难例挖掘（多引擎全漏 + 引擎冲突） | 降低误报 |
| **Unknown** | 分歧 / 极小 / 遮挡 | **不当普通背景负样本**，留在待决队列 |

两条纪律：**先按父视频隔离划出隐藏集**，再谈训练；自动标注量增加**不构成换模型的理由**。

## 伪标签怎么筛

- 开放词表教师出框 + 跟踪器多帧聚合取中位数收紧——实测优于让 VLM 直接标；
- 人工精标 200–800 帧作为干净验证集（**训练可以脏，验证必须干净**）；
- 合成渲染车牌补「人眼可读但检测难」的样本；
- 训练侧的配套手段：box jitter 抗噪声、RepGT loss 防框不包全、车-牌空间关系 loss；
  打码框外扩 5–15% 做安全边际。

## 端侧接入

- 部署包只放轻量检测器 + 跟踪 / 时序模块，**教师全部留在离线**；
- **砍掉 OCR**：打码只需要定位，识别能力不进部署包；
- 量化优先 **w8a32 / w8a16**：权重 int8 影响小、激活 int8 会明显掉召回；
- **校准集必须含真实车牌场景**（远距 / 模糊 / 夜间），否则 int8 会崩——
  源项目记录过一例校准不当后的检测指标从 0.61 掉到 0.32
  （历史记录，本仓库没有复现）；
- 低频检测（1–5 Hz）+ 轨迹预测补中间帧，两遍法弥补低频漏检；配温度阈值做降频保护；
- 端侧路径 CoreML / NCNN / RKNN / TFLite；
- 未来可加「风险头」，但它只决定是否升级 ROI / 回溯，**不能凭几何生框**。

> 端侧实机的实际帧率与功耗**未测**，拿到实机前不作任何声明。

## 数据从哪里来（现状）

训练回流的上游是素材，而素材目前**没有一条**达到可用状态：

- 目录里的国内真实源全部保持隔离态、`authority=eval_only`；
- 一份 1,848 张的几何数据集**不是**广度数据集：11 个 parent、只有几何框、
  无逐帧可读性 GT、其中两个子集还同属一个 parent、另有 6 组精确重复图；
- 公开数据集的权利链核查结论是：**没有**可直接升级为通过状态的国内真实视频集，
  公开数据最多用于隔离的 warm-start、负样本和主动学习候选。

完整的入库门禁、采集批次、停止条件与退出门槛见
[数据获取与评测方法论](evaluation.md#8-素材目录与入库门禁)。
